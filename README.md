# Urban Mobility and Intelligence

An interactive Power BI report that analyzes urban mobility data to help understand how people move through a city and where transport systems can improve.

## Overview
This project turns raw mobility data into interactive visuals and KPIs, making it easier to spot trends, peak periods, and problem areas in urban transportation.

## Key Features
- Interactive dashboards with filters and slicers
- Analysis of travel patterns, peak hours, and demand trends
- Comparison across regions, routes, or transport modes
- KPI cards and charts for quick decision-making

## Tools Used
- Power BI Desktop
- DAX and Power Query for data modeling and transformation

## Getting Started
1. Download `urban mobility and intelligence.pbix`
2. Open it in Power BI Desktop
3. Explore the report pages and use the slicers to filter the data
